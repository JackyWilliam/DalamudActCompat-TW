# DACT 修復工具（衛月外掛）

這是與 DACT 主外掛分開的 **Dalamud 外掛**，在同一個自定義外掛倉庫內安裝。不是 Windows 軟體，無需下載或執行 EXE。

## 使用者操作

1. 在 `/xlplugins` 重新整理列表，搜尋並安裝 **DACT 修復工具**。
2. 在已安裝列表中**停用 DACT 主外掛**，不要解除安裝它；保持修復工具啟用。
3. 開啟修復工具（或輸入 `/dactrepair`），點選 **備份並修復到 0.4.4.0**。
4. 提示完成後，完整重啟一次遊戲並重新啟用 DACT。修復工具隨後可以解除安裝。

已有 DACT 倉庫無需另加地址：

```text
https://raw.githubusercontent.com/JackyWilliam/DalamudActCompatRepo/main/pluginmaster.json
```

只處理錯誤編號 **4.4.0.0 → 0.4.4.0**。普通舊版本正常更新即可，已經是 0.4.4.0 會顯示無需修復。

## 修改範圍

- 內建 SHA-256 固定的正式 0.4.4.0 核心包，同步修正真實 DLL、清單和安裝目錄，包含換膚影響統計背景的修復。點選修復時無需聯網。
- 只定位當前啟動器中 DACT 的安裝目錄，不掃描其他使用者或另一個啟動器；開發載入不會修改真實安裝。
- 原錯誤目錄及衝突的目標目錄備份到啟動器資料目錄的 `DACTRepairBackups/时间-随机编号/`。備份不在 `installedPlugins` 內，避免衛月清理舊版本時將其刪除。
- 不讀取或改寫 `pluginConfigs`，保留帳號、皮膚、觸發器等配置。保留 WorkingPluginId、訂閱來源和禁用狀態；更新後需重新啟用主外掛。
- DACT 主外掛或 Host 仍在執行、檔案被佔用、存在較新版本、安裝損壞標記或目錄聯接時停止。失敗自動恢復舊安裝；若檔案鎖等阻礙恢復，保留錯誤提示中的備份目錄並聯系維護者。
- 修復完成後應重啟遊戲，**不要在當前會話重新啟用舊 DACT 例項**。衛月重啟後才會按新目錄重新發現正確版本。

不會注入遊戲、改遊戲檔案、結束程序或呼叫衛月私有解除安裝介面。

## 開發

`tools/DACT.Repair/build.ps1` 使用 .NET 10 和 Dalamud API 15 構建獨立外掛，下載並校驗固定核心包。可用 `-CorePackage` 和 `-DalamudLibPath` 指定已有包與引用。

隔離測試覆蓋真實正式包、備份、配置/其他外掛/身份不變、重複執行、三處失敗恢復、執行狀態與競爭、壞包/清單、檔案鎖、目錄聯接及 ZIP 越界。設定 `DACT_TEST_CIMGUI` 和 `-PreviewPath` 時，還使用真實 cimgui 驗證執行中/修復中/無需修復時的點選限制。測試不觸碰實際安裝。

只分發 `DalamudActCompatRepair-0.1.0.0.zip` 和校驗檔案。該 ZIP 是衛月外掛包，不要雙擊 DLL，也不要手動覆蓋主外掛目錄。
