# 介面翻譯

DACT 支援簡體中文、繁體中文、英語、日語、德語和法語。UI 語言與遊戲區域、解析器語言分別儲存。

- 簡體中文和英文文案保留在 `UiText.Get(中文, English)` 呼叫處。其餘四種語言的 JSON 以可見英文文案為鍵，編譯時嵌入程式集，執行時無需網路。
- 新增或修改英文文案時，同步更新四個 JSON。找不到翻譯時顯示英文，避免空白控制元件。
- 帶引數的文案使用 `UiText.Format(中文插值字符串, 英文插值字符串)`，保留 `{0}`、`{1:N0}` 等佔位符及格式。不要先拼接引數再查翻譯；帳號、聊天、備註、路徑不能成為翻譯鍵。
- `##` / `###` 後的 ImGui 標識由程式碼保留，不放入翻譯鍵或譯文。命令及外掛名稱保持原樣。
- 新增伺服器狀態對映在 `SystemStatusText` 中使用完整匹配；未知診斷保留原文。不要對使用者資料做全域性替換。
- 日語職業名稱按日服稱謂顯示。德語和法語保持既有職業縮寫規則。
- 日語中的 FFLogs 百分位評分（Parse）統一稱為「パース」；統計範圍（Parse scope）使用「集計範囲」，日誌解析與解析器保留「解析」「パーサー」。片假名複合詞不插空格，日文句號後不額外插入空格；命令、路徑和引數格式保持原樣。
- 德語統一使用 Sie / Ihr 稱呼使用者。角色面板使用 Charakterfenster（德語）和 fiche de personnage（法語）；幫助中應明確區分實際命中比例與角色面板顯示值，避免 character 被誤解為文字字元。

檢查：Release 構建後執行 PackageSmokeTests 的 `--localization-only`。原生介面測試還覆蓋語言選單點選、窄視窗和字型縮放。翻譯採用機器輔助初稿並校訂核心術語和常用流程；長篇幫助仍可繼續由母語使用者潤色。
