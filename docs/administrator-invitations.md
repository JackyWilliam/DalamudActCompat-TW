# 管理員啟用碼許可權

服務端使用者詳情頁可開啟或關閉管理員身份。該身份提供客戶端無限生成啟用碼的許可權；一次一碼、受邀好友資訊和服務端封禁規則保持生效。管理員期間的生成記錄保留邀請關係，不消耗普通額度，關閉身份後恢復原普通額度。

客戶端登入或恢復共用登入時，從邀請列表讀取身份；線上期間使用原有 30 秒會話心跳同步身份。客戶端按鈕只負責展示可用狀態，每次生成仍由服務端讀取最新身份校驗。

晉升彈窗以短暫淡入、輕微縮放和金色粒子慶祝，動畫約兩秒後停止，保留“我知道了”按鈕。通知由服務端儲存，每次授予有獨立標識；只有本人確認後才標記已讀，離線、重啟和讀取不會丟失通知。取消再授予會重新提醒。切號、退出和撤銷身份後，原帳號彈窗關閉。

使用使用者提供的 `Player26_Icon.png`，原圖隨客戶端打包。好友列表、自己的帳號、申請/查詢結果、聊天姓名和訊息提示中的管理員姓名後顯示同一圖示。身份來自服務端當前 `isAdmin`；撤銷時服務端更新會話修訂號，使歷史訊息姓名標識也在下次好友同步時消失。

新增介面和欄位：

- `GET /api/v1/auth/me`：可選 `administrator`，包含 `isAdmin`、`adminGrantId`、`adminNoticePending`。
- `GET /api/v1/invitations`：同名身份欄位與 `quotaUsed`；`used` 保持總生成數，普通額度數值欄位保留。
- `POST /api/v1/auth/administrator-notice/ack`：僅提交當前顯示通知的 `adminGrantId`，以當前登入帳號確認。舊通知標識不能確認新一輪晉升。

舊服務端沒有這些欄位時，客戶端預設普通身份。需更新客戶端才能顯示管理員許可權和晉升彈窗。

驗證入口：PackageSmokeTests 的 `--administrator-only`；`DACT_TEST_CIMGUI` 可啟用真實原生渲染和按鈕互動驗證，`DACT_NATIVE_UI_OUTPUT` 可儲存動畫幀。隔離服務端透過 `DACT_ADMINISTRATOR_FIXTURE` 執行真實 C# 自動登入、超過預設額度生成、確認和冷啟動不重播的聯調。測試始終使用臨時帳號與資料目錄。
