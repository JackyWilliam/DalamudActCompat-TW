# Cactbot user 目錄與統計重置

## Cactbot user 目錄

在“懸浮窗 → Cactbot 設定”中選擇 user 目錄，會開啟由該設定視窗持有的原生對話方塊。可以填寫完整路徑、瀏覽資料夾或恢復預設；取消保留原路徑。選擇目錄不會自動搬移舊指令碼，請將需要的檔案放進所選目錄。

自定義本地目錄參與原有加密雲備份，包括指令碼、時間軸及其他資源。備份仍使用原來的 `DalamudActCompat/cactbot_user` 邏輯名稱，舊備份可以繼續恢復。恢復時保留當前電腦已配置且存在的目錄；新電腦未配置目錄時恢復到預設目錄。來自備份的絕對路徑不作為寫入目標。現有路徑聯接限制保持，直接選擇真實目錄即可。

跨盤恢復先在目標盤暫存，並在修改配置前生成加密回滾包。恢復預覽比較實際目錄；恢復失敗會撤銷已提交的目錄和配置。路徑互相包含、備份檔案位於 user 目錄內等情況會被拒絕。

## 統計重置

“戰鬥統計 → 統計重置方式”有兩個選項：

- **DACT預設**：舊配置和新安裝均預設使用，保持原有累計及結束規則。
- **脫戰指定秒數後重置**：使用者填寫 0–3600 秒，初始輸入值為 5 秒。重新進入戰鬥取消倒計時；本人死亡但隊伍仍在戰鬥時也不會觸發。到期儲存結果並清空統計，下次從零計算。

該設定基於戰鬥狀態，不按 Boss 身份識別。真實脫戰較長的轉階段也可能分開，按需調整等待時間。副本內每次結算儲存在同一副本歷史資料夾內；副本外按獨立戰鬥儲存。

重置使用獨立的統計分段，不呼叫共享 ACT 的 `EndCombat`，不停止日誌分發，不向相容 Host 額外發布戰鬥結束。重置後同一底層 ACT encounter 的後續動作複製到私有統計物件，避免傷害、最高命中、DPS 時長帶入上一場。Cactbot 的真實遊戲/ACT 戰鬥狀態及郵差介面保持。

## 艾歐澤亞皮膚

艾歐澤亞改為贊助 **3 級及以上**解鎖。皮膚收藏、詳情和贊助入口提示共用同一等級定義；1、2 級的贊助圖示與紅色名字繼續保留。資格仍由伺服器返回的當前帳號等級判斷，本地配置和雲備份不能授予皮膚。既有選擇保留，未達到等級時顯示預設皮膚。
