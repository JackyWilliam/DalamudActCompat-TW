# v0.4.4.5

## 自動解析範圍與液態玻璃修復

- 「概覽 → 基礎設定 → 遊戲解析範圍」新增「自動（按實際組隊）」：單人時僅自己，普通小隊時小隊成員，24人團隊時團隊成員；進隊、退隊後自動切換。
- 自動判斷跟隨實際組隊狀態，不受戰鬥統計視窗8/24人佈局影響；現有手動選擇保持不變，選擇「自動」後即可啟用。
- 自動範圍同時用於解析器、傷害補算、治療、死亡觀測和DPS計時，支援配置儲存及雲同步恢復，已記錄資料保留；原始日誌與觸發器不受影響。
- 修復液態玻璃白色卡片出現生硬方框的問題：去除重複疊加的底色和邊框，恢復完整圓角及滾動裁剪，讓卡片保持輕透；視窗偏白底色、黑色文字和折射效果保留。

## 更新說明

使用原衛月訂閱正常更新，更新後請完整重啟遊戲。現有配置和已發現皮膚均保留。

仍安裝錯誤編號 `4.4.0.0` 的使用者，請先用同一倉庫中的 **DACT 修復工具** 修復到 `0.4.4.0`，完整重啟後再更新到 `0.4.4.5`；無需重置配置。
