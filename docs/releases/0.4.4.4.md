# v0.4.4.4

## 遊戲解析範圍

- 在「概覽 → 基礎設定」新增「遊戲解析範圍」，支援所有人、僅自己、小隊成員、團隊成員四檔，預設保持所有人。
- 小隊成員指自己所在的小隊，團隊成員包含其他小隊；支援24人團隊中不同的A、B、C隊歸屬，召喚物按主人歸屬統計。
- 切換後立即作用於後續統計，無需重啟解析器，已經記錄的資料保留。
- 解析器、傷害補算、治療、死亡觀測和DPS計時使用一致的範圍，避免被排除的隊員重新進入統計或拉長計時。
- 解析範圍隨配置儲存和雲同步恢復；原始日誌繼續完整輸出，原有觸發器保持可用。

## 更新說明

使用原衛月訂閱正常更新，更新後請完整重啟遊戲。現有配置和已發現皮膚均保留。

仍安裝錯誤編號 `4.4.0.0` 的使用者，請先用同一倉庫中的 **DACT 修復工具** 修復到 `0.4.4.0`，完整重啟後再更新到 `0.4.4.4`；無需重置配置。
