# v1.0.0.1 台服測試候選版

移植原專案 DACT 1.0.0.1，台服以自身 API 13 / .NET 9 依賴重新構建與驗證。維持台服倉庫、繁體中文預設與既有台服解析、FFLogs TW 查詢及 SilverDasher 台服資料表。

## 本次更新

- **修復介面抖動**：遊戲的介面縮放不是整數倍時（衛月預設字號就是這種情況），登入／註冊／找回密碼頁和 Discord 綁定頁的表單會一直上下抖動；好友聊天的輸入區和訊息列表也會跟著抖。現在這些位置都對齊到整像素，不再抖動。
- **開場動畫可設定**：設定 → 一般 → 開場動畫，可選「每次啟動遊戲後首次開啟時播放」（預設，與 1.0.0.0 相同）、「每次開啟控制中心都播放」或「關閉」。播放時點一下仍可跳過。

## 使用說明

透過台服獨立訂閱更新至 1.0.0.1，完成後請完整重啟遊戲。這次不需要重新登入。

## 驗證範圍

台服 Release 構建，以及 Scanner、Package、Host、Legacy Resource 冒煙測試通過；帳號原生介面測試新增 100%–140% 多種縮放與逐像素視窗高度下「表單不再移動」的檢查，以及開場動畫三種模式的檢查；好友、說明與封禁恢復原生介面測試通過。說明截圖以台服構建重新產生。

**本版尚未在台服遊戲內實機驗證**，維持測試候選版。
