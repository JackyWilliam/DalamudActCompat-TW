# v0.4.5.0

## 本次更新

- 好友列表新增右鍵設定、修改和清除備註。備註會隨 DACT 帳號自動同步，換電腦後可繼續使用；好友列表、聊天和訊息提醒保留原帳號名以便辨認。
- 修復 Cactbot 設定視窗無法選擇 user 目錄的問題，支援瀏覽或直接輸入自定義路徑；自定義目錄中的指令碼、時間軸及配置可隨加密雲備份恢復。
- 戰鬥統計新增“DACT預設”和“脫戰自定義秒數重置”。預設保留此前行為，選擇脫戰重置後可自行輸入等待秒數。
- “艾歐澤亞”皮膚調整為贊助 3 級及以上解鎖；1、2 級的贊助圖示和紅色名字保留。
- 更新抹茶的動態事件、FATE、副本及世界資料，修正抹茶和銀山雀兒的 FATE 適配，以及抹茶的跨服排隊事件適配。
- 修復擴充套件 DLL 未變化時資料包升級被漏過的問題，擴充套件更新保留原來的啟用或禁用狀態。

## 使用說明

- 備註最多 40 字，支援留空清除；兩臺裝置同時修改時會提示重新編輯，避免覆蓋另一臺裝置的新備註。
- 脫戰重置只分段戰鬥統計，原有觸發器、郵差等擴充套件的戰鬥事件流程保持。
- 自定義 Cactbot 目錄在本機保留；換電腦恢復配置時使用該電腦設定的目錄，不照搬另一臺電腦的磁碟機代號。
- 更新後請完整重啟遊戲，以載入本次配套解析元件與擴充套件資源。
