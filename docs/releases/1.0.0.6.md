# v1.0.0.6 台服測試候選版

移植原專案 DACT 1.0.0.4 中與 7.58 無關的三項修復，以及 1.0.0.6 的全部內容（台服跳過 1.0.0.4、1.0.0.5，直接與原專案版本號對齊）。原專案 1.0.0.4、1.0.0.5 的 7.58 適配、解析器 3.0.3.5 與 Unscrambler 7.58.0 只對應國服與國際服 7.58，台服遊戲仍為 7.25，不在本次範圍。台服以自身 API 13 / .NET 9 依賴重新構建與驗證，仍發布包含 Host 的完整候選包，安裝方式不變。

## 本次更新

- **修復開著加速器時 AI 助手連不上**：網易 UU 等加速器會把遊戲程序的所有網路連線轉到自己的線路，DACT 以前在遊戲程序裡發 AI 請求，也被一起轉走，結果 Claude、ChatGPT 等國外服務一直連不上。現在 AI 請求改由 DACT 自帶的獨立小程序發出，不再被加速器轉走。這個程序只負責轉發 AI 請求、不載入任何 ACT 擴充功能，API Key 仍只在本機使用；它和以前一樣跟隨系統代理與「介面位址」設定。
- **AI 錯誤提示更準確**：服務商依地區拒絕請求時，不再誤報「這個 Key 沒有權限使用該模型或介面」，而是說明是網路出口地區不被支援並提供處理方式；其他權限問題會附上服務商的原話。
- **「脫戰隱藏」可以延遲**：開啟「脫戰隱藏」後可以選擇脫戰後多久再隱藏——立即、10 秒後、30 秒後、1 分鐘後或 2 分鐘後，方便看完上一場；倒數期間重新進入戰鬥會一直顯示。懸浮窗在「懸浮窗」頁的「隱藏時機」設定，戰鬥統計在「自訂…」上方「脫戰隱藏」旁邊設定。預設仍是脫戰立即隱藏。
- **還原雲端備份時保留本機的「遊戲區域」**：以前在另一台電腦或另一個用戶端（例如國服的備份還原到台服）還原雲端設定時，會連「遊戲區域」一起帶過來，使台服用戶端被當成其他區域解析。現在還原時和日誌目錄一樣保留本機原本的選擇。
- **修復懸浮窗設定缺少 WebSocket 位址時解析器無法啟動**：懸浮窗設定檔存在、但裡面沒有 WebSocket 位址時，解析器會整個啟動失敗（錯誤含 OverlayPlugin WebSocket server could not be started），戰鬥統計和懸浮窗都不可用。現在會自動改回預設的 127.0.0.1:10501；自行設定過的位址與連接埠不受影響。
- **修復寶寶椅讀到舊的實體資料、播報方位錯誤**：觸發器在連線日誌到達的那一刻讀取連線來源的位置來判斷誰被點名。DACT 以前可能在實體資料同步到位之前就把日誌交給寶寶椅，位置剛變化或剛出現的實體會讀成舊值，被點名的人聽到另一組的方位（正好是對角）。現在每條日誌會等「在它之後採集的那份實體資料」到達再交給寶寶椅，通常只多等一兩幀，最長 150 毫秒。
- **修復好友頁一直「正在讀取狀態…」**：把 DACT 設定帶到另一台電腦或另一個 Windows 帳號後，本機的聊天暫存檔在新環境解不開，好友列表會一直卡在讀取。現在會把這個檔案另存為 `.unreadable`（不刪除）並重新開始，好友、狀態和聊天恢復可用，同時提示一次。

- **說明頁截圖改為完整尺寸**：台服以前的說明截圖經過裁切縮小，控制中心右側與下方被裁掉一截；現在與原專案一致，使用完整的 940×660 原始截圖。候選包因此大約增加 4 MB。

## 使用說明

透過台服獨立訂閱更新至 1.0.0.6，完成後請完整重啟遊戲。這次不需要重新登入，設定、好友和雲端備份都不受影響。

## 驗證範圍

台服 Release 構建，以及 Scanner、Package、Host、Legacy Resource 冒煙測試通過。新增檢查：AI 中轉以真實 Host 與本機模擬服務商核對請求確實由獨立程序發出、5 MiB 請求原樣往返、Claude 官方 SDK 也走中轉、取消會中斷上游、遊戲結束後中轉隨之結束、缺少 Host 時退回直連，以及地區拒絕與一般權限錯誤的文案；脫戰隱藏延遲（預設立即、延遲內顯示、重新進戰取消、上限與舊設定遷移）；還原雲端備份保留本機遊戲區域；懸浮窗 WebSocket 位址修復；寶寶椅等待實體採集（含 U7b P1 連線擊退回歸，CI 執行）；好友頁聊天暫存檔讀不出。說明截圖以台服構建重新產生。

**本版尚未在台服遊戲內實機驗證**，維持測試候選版。AI 中轉與脫戰隱藏延遲已由開發者在國服用戶端實測。
