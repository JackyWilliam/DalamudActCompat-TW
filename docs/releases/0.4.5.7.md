# v0.4.5.7

## 本次更新

- 統一管理 Cactbot 文字提醒、時間軸、HTML 模板和自定義網址懸浮窗，使用同一列表及常規、快捷鍵、來源設定頁。
- 保留獨立的 Cactbot 設定、解析器與資源狀態、安裝/更新、官方專案及異常處理入口，並改善窄視窗和多語言排版。
- 新增每個懸浮窗獨立的全域性快捷鍵，可切換顯示/隱藏、開啟/關閉、滑鼠穿透和位置鎖定，支援錄製、啟停、刪除及衝突提示。
- 修復多款純色皮膚中首頁及其他按鈕與卡片背景同色的問題，區分普通、懸停、按下和已開啟狀態。
- 修復部分自定義網頁在自動補全路由後無法連線解析器的問題；原網址可繼續使用，更新後重新開啟懸浮窗即可。
- 隔離單個動態圖形重新整理異常，避免其阻斷其他圖形重新整理和過期清理，改善連續戰鬥中的繪圖穩定性。

## 更新說明

- 請透過原外掛訂閱更新，並完整重啟遊戲以載入新版本。
- 懸浮窗原有網址、位置、大小和顯示設定繼續保留；修改來源或重新檢測連線時保留獨立的手動隱藏及啟動偏好。
- 快捷鍵在各懸浮窗的“快捷鍵”頁設定；系統或其他程式佔用的組合鍵會顯示衝突提示。
