# v0.4.5.20 台服測試候選版

台服以自身 API 13 / .NET 9 依賴移植、構建與驗證。維持台服倉庫、繁體中文預設與既有解析適配，不包含 Matcha。

## 本次更新

- 相容 Triggernometry 2.4.3.0：中文維護版 2.4.3.0 為了能取消已排隊的動作，調整了動作執行入口的參數。DACT 的相容改寫因此失配，Triggernometry 無法載入，擴充套件頁「打開設定」沒有反應。現已相容，隨包 Triggernometry 同步更新至 2.4.3.0。

## 驗證邊界

相容改寫在 Triggernometry 2.4.1.1 與 2.4.3.0 上均通過 Host 與行程內兩條改寫路徑及 IL 靜態校驗；台服 CI 以真實 2.4.3.0 在 .NET 9 上執行 Host、U7b 初始化順序、事件時間基準、繪圖診斷與清特效鏈回放。

Triggernometry 2.4.3.0 自身的功能與語義變化（例如新增的「終止本次觸發中的全部動作」、打斷已排隊動作的範圍）由上游維護，本版只保證其在 DACT 中載入、打開設定並沿用既有相容橋接。台服原生重繪、封包 hook、VFX 等遊戲內行為與觸發器實戰表現仍待驗收，本版維持測試候選版。

已透過擴充套件更新器裝上 Triggernometry 2.4.3.0 的使用者，更新後觸發器會恢復載入；仍為 2.4.1.1 的使用者可繼續使用，也會在確認隨包更新後切換到 2.4.3.0。透過台服獨立訂閱更新，完成後請完整重啟遊戲。
