# v0.4.4.6

戰鬥統計新增「顯示範圍」，入口位於外掛主介面的「戰鬥統計」欄目。

- **按榜單設定**：預設選項，沿用原來的 8/24 人、隊伍選擇和僅自己等顯示設定。
- **跟隨解析範圍**：按「概覽 → 基礎設定 → 遊戲解析範圍」顯示已記錄的玩家。「所有人」可顯示隊外玩家；「自動」跟隨實際單人、小隊或團隊狀態。經典榜、橫版和職能分欄均支援。
- 切換顯示範圍會同步更新排名、佔比和合計，保留已有統計；切回後恢復各榜單原有的篩選設定。選擇可儲存並隨雲配置恢復。
- 跟隨模式下，經典榜的 8/24 人按鈕顯示為「列表／平鋪」，用於切換佈局；人數由解析範圍決定。

解析範圍隻影響實際收到並記錄的資料；擴大範圍不會補回之前未解析的資料，舊歷史記錄也不會憑空增加隊外玩家。

更新後請完整重啟遊戲，以載入配套解析元件。
