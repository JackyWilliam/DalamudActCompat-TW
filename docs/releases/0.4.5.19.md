# v0.4.5.19 台服測試候選版

台服以自身 API 13 / .NET 9 依賴移植、構建與驗證。維持台服倉庫、繁體中文預設與既有解析適配，不包含 Matcha。

## 本次更新

- 相容 Triggernometry 2.4.1.1：中文維護版 2.4.1.1 重構了動作執行，DACT 先前無法載入它，擴充套件頁「打開設定」沒有反應。現已相容，隨包 Triggernometry 同步更新至 2.4.1.1。
- 外掛清單補上 512 像素 PNG 圖示網址：Dalamud 會保留安裝包內的清單，先前清單沒有圖示網址，讀取已安裝外掛資訊的工具拿不到圖示。台服訂閱圖示同步改為 512 像素 PNG。

## 驗證邊界

相容改寫在 Triggernometry 2.3.0.0 與 2.4.1.1 上均通過 Host 與行程內兩條改寫路徑、改寫後結構斷言及 IL 靜態校驗；台服 CI 以真實 2.4.1.1 在 .NET 9 上執行 Host、U7b 初始化順序、事件時間基準、繪圖診斷與清特效鏈回放。

Triggernometry 2.4.1.1 自身的功能與語義變化由上游維護，本版只保證其在 DACT 中載入、打開設定並沿用既有相容橋接。台服原生重繪、封包 hook、VFX 等遊戲內行為與觸發器實戰表現仍待驗收，本版維持測試候選版。

已透過擴充套件更新器裝上 Triggernometry 2.4.1.1 的使用者，更新後觸發器會恢復載入；仍為 2.3.0.0 的使用者可繼續使用，也會在確認隨包更新後切換到 2.4.1.1。透過台服獨立訂閱更新，完成後請完整重啟遊戲。
