# v0.4.5.3

## 本次更新

- 新增繁體中文、日語、德語和法語介面，連同簡體中文與英語共支援六種語言，可在「設定與帳號 → 介面語言」即時切換。
- 新增「聽雨窗」彩蛋皮膚：灰藍雨窗、附著玻璃的細密水滴和動態滑落水痕，支援背景折射與柔和高光。
- 補齊好友狀態、備註、聊天、快捷回覆、統計預覽、幫助，以及擴充套件更新、FoxTTS 切換和記憶體保護等常用提示的翻譯。
- 改善長文案在窄視窗與大字型下的顯示：導航標籤可縮略並懸停檢視全文，好友備註按鈕會按空間自動換行。

## 更新說明

- 請透過外掛管理器更新，並完整重啟遊戲以載入新版本。
- 原有帳號、皮膚、好友備註、觸發器和語音設定保留。
- 本次多語言適配覆蓋 DACT 自身介面；第三方外掛的介面、原始通知和診斷仍由對應元件決定語言。
