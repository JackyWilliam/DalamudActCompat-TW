# v1.0.0.3 台服測試候選版

移植原專案 DACT 1.0.0.2 與 1.0.0.3（台服跳過 1.0.0.2，直接與原專案版本號對齊），台服以自身 API 13 / .NET 9 依賴重新構建與驗證。維持台服倉庫、繁體中文預設與既有台服解析、FFLogs TW 查詢及 SilverDasher 台服資料表；台服仍發布包含 Host 的完整候選包，安裝方式不變。

## 本次更新

- **Triggernometry 收日誌不再被誤判卡住**：日誌引用了剛出現、還沒同步過來的 NPC 時，DACT 會讓 Triggernometry 最多等 200 ms 再收這條日誌，好讓觸發器讀得到這個 NPC。以前把日誌裡所有「以 4 開頭的 8 位十六進位數」都當成 NPC 編號，狀態剩餘時間（例如 41A00000 其實是 20 秒）、傷害值、職業量譜和記憶體數值也被當成 NPC，每出現一個新數值就白等 200 ms；戰鬥中每秒會發生好幾次，觸發、TTS 和繪圖會一直晚 0～0.2 秒。現在只檢查日誌裡真正存放 NPC 編號的欄位，真正剛出現的 NPC 仍然會等。
- **擴充功能缺少必需權限時直接說明缺哪項**：銀山雀兒（SilverDasher）等擴充功能需要某項權限才能啟動（銀山雀兒需要「訪問遊戲原生記憶體」），在預設的安全權限下以前會顯示「故障」和一整段錯誤訊息。現在顯示「需要授權」，並提示在「權限」裡開啟哪一項，開啟後擴充功能會自動重新啟動。
- **權限檢查日誌不再刷屏**：同一項權限的檢查結果只記一次，權限變更後重新記錄；鯰魚精郵差（PostNamazu）未授權時也不再每 10 ms 記一條拒絕。
- **開場動畫「每次開啟」修復**：動畫沒放完就關掉控制中心，以前動畫會在背景繼續計時，再開啟時要麼從上次的進度接著放，要麼直接進主介面不播放。現在關閉控制中心就會結束動畫，下次開啟總是從頭播放；在關閉的淡出過程中立刻重新開啟也算一次新的開啟。
- **開荒進度的階段與 FFLogs 一致（光暗未來絕境戰）**：以前按「血量最高的敵人換了名字」算階段，冰水晶轉場和 P4 雙 Boss 回歸都會多算一個階段，最多顯示到 P7。現在按 FFLogs 的劃分 P1–P5（冰水晶轉場仍算 P2、P4 為雙 Boss）。以前記下的絕境戰紀錄在更新後開啟時會自動按新規則重算（需和記錄時是同一種用戶端語言）。其他副本的階段演算法不變。
- 同步原專案的 Host 版本規則：Host 只使用與外掛同版本的檔案，不會改用舊版本。台服的 Host 一直隨完整候選包安裝，不需另外下載，這項對台服使用者沒有可見變化。

## 使用說明

透過台服獨立訂閱更新至 1.0.0.3，完成後請完整重啟遊戲。這次不需要重新登入，設定、好友和雲端備份都不受影響。

## 驗證範圍

台服 Release 構建，以及 Scanner、Package、Host、Legacy Resource 冒煙測試通過。Host 冒煙新增「狀態剩餘時間、傷害值、量譜和記憶體數值不會讓 Triggernometry 等待，而新出現的 NPC 仍會等待」與「缺少權限時報出具體權限名、同一權限結果只記一次」的檢查，事件時間探針改用施法行引用新 NPC；Package 冒煙新增「快取裡有舊版 Host 包且下載全部失敗時不使用舊版本」、開場動畫「關閉後或淡出中重新開啟都從頭播放」與光暗未來絕境戰階段（逐次採樣、轉場留在 P2、舊紀錄重算與儲存、其他語言與其他副本不改）的檢查。上述新增檢查均已確認在移植前的程式碼上會失敗。說明截圖以台服構建重新產生。

**本版尚未在台服遊戲內實機驗證**，維持測試候選版。
