# v1.0.0.11 台服測試候選版

移植原專案 DACT 1.0.0.8 至 1.0.0.11 的全部內容（台服跳過 1.0.0.7 至 1.0.0.10，直接與原專案版本號對齊）。原專案 1.0.0.7 補的是國服與國際服 7.58 的 FATE／跨服排隊封包編號，台服不適用，不在本次範圍。台服以自身 API 13 / .NET 9 依賴重新構建與驗證，仍發布包含 Host 的完整候選包，安裝方式不變。

## 本次更新

- **開荒進度的階段不再亂跳**（玩家回饋：絕亞顯示「最遠 P8」，絕神兵剛見泰坦就顯示 P5）：以前只有光暗未來有自己的階段表，其他副本按「場上血量最高的敵人換了名字」來數階段。兩個 Boss 同場時，誰暫時選不中就輪到另一個當最大目標，每輪多數一個階段；分身、小怪和後面階段回場的 Boss 也會再數一次。
  - 七個絕本現在都按各自的階段表來數：絕巴哈、絕神兵、絕亞、絕龍詩、絕歐米茄、光暗未來、絕妖星。只有該階段自己的 Boss 可以選中時才進入下一階段，轉場算在前一個階段裡。
  - 絕歐米茄的 P4（藍屏）和絕妖星的 P2、P5 與前一階段是同一個名字的 Boss，靠 Boss 的血條重新回滿來識別。
  - 其他副本（零式、極神等）：同場一起打的敵人互相換位不再算新階段；Boss 離場後才出現的小怪、Boss 回場仍然各算一個階段。
  - 以前記下的記錄會在更新後自動按新規則更正，不需要清資料。
- **人多的戰鬥不再嚴重掉幀**：開著 DACT 打團隊副本和野外大規模戰鬥時掉幀很嚴重。原因是每一次技能命中 DACT 都會重新整理一遍整場戰鬥的資料，周圍人越多、打得越久就越慢。現在戰鬥中的資料最多每 0.1 秒整理一次，開打的第一下仍然立即顯示，戰鬥結束時的資料照常完整，榜單看不出差別。
- **人多時同步給 Host 的資料減少約一半**：DACT 每 30 毫秒把周圍角色的位置、血量和增益減益同步給執行觸發器的 Host。現在增益減益沒有變化的角色不再重發這一部分，同一份資料只打包一次給所有 Host 共用，Host 只重建有變化的角色，沒有 Host 在執行時不再採集。
- **戰鬥統計不再被旁人的戰鬥帶著計時**：野外單人、沒有組隊也沒開打時，附近只要有人打木人或打怪，戰鬥統計就開始計時。
  - 「解析範圍」的預設值改為「自動（按實際組隊）」：單人只統計自己，小隊統計小隊，24 人團隊統計團隊。
  - 原來是「所有人」的設定，更新後會改成「自動」一次；想繼續看附近所有人的資料，在「首頁 → 一般 → 解析範圍」改回「所有人」即可，之後不會再被改動。
- **職能分欄榜單不再一直帶著捲軸**：「D / T 傷害榜」和「治療 HPS 榜」展開或收起時多出的捲軸已修好，行數確實放不下時才在列表裡捲動。
- **寫回饋時不再鎖住遊戲，描述框會自動換行**：回饋改為可以拖動的獨立視窗，寫到一半可以回遊戲看一眼再接著寫；描述框中文逐字換行、英文按詞換行，提交的仍是原文。
- **副本裡的每一把，最新的排在最上面**：「戰鬥紀錄 → 近期戰鬥」展開一次副本後，最新的一把在最上面，編號不變。
- **橫版榜單可以按視窗寬度收窄**：在「戰鬥統計 → 榜單範本 → 自訂… → 橫版 → 視窗外觀」開啟「視窗放不下時收窄模組」後，視窗放不下全隊時會平均收窄每名玩家的格子。這個開關預設關閉。橫版的全隊總傷害、總治療也不再隨視窗拉長。
- **懸浮視窗「⋯」選單裡的說明對齊了；新增 Cactbot 懸浮視窗時，下拉選單同時顯示本地名和原名**，例如「職業量譜 / Jobs」。
- **隨包 Cactbot 更新到 0.37.6**：已經裝過的 Cactbot 會在更新 DACT 後自動升級，`cactbot/user/` 裡自己的檔案保留。
- **適配仿生石（Simulant）v0.1.0.0**：可以匯入 v0.1.0.0，v0.0.4.2 繼續支援；更高的版本不載入並說明原因。仿生石自帶的自動更新在 DACT 裡不執行，要換版本請重新匯入 DLL。
- **隨包的鯰魚精郵差帶上了呼叫排程器**（仿生石 v0.1.0.0 需要它）：改為按上游原始碼（提交 `521007c`）建置的版本，版本號仍顯示 1.3.6.6。更新後第一次啟動會請你確認一次這項變更，確認後郵差才會載入；這份郵差不再跟隨線上更新。
- **缺少 WebView2 Runtime 時提示正確的原因**：系統裡沒有 Microsoft Edge WebView2 Runtime 時，Cactbot 等網頁懸浮視窗打不開，以前卻提示「隨包的 WebView2Loader.dll 缺失，請重新安裝外掛」。現在提示安裝微軟官方的 WebView2 Runtime。
- **診斷日誌保留完整的錯誤資訊**：「複製診斷日誌」和回饋裡附帶的日誌，現在會保留出錯的整段記錄，其他外掛的日誌和以前一樣不會帶上。

## 已知情況

- **本版尚未在台服遊戲內實機驗證**，維持測試候選版。階段不對時請在 DACT 裡點「回饋」，寫上是哪個副本、打到哪裡、顯示成了第幾階段。
- 開荒進度：除絕亞外，其他絕本的階段劃分依據的是攻略資料和 Cactbot 時間軸，沒有逐一拿 FFLogs 的階段列表核對。絕歐米茄 P4、絕妖星 P2 / P5 若前一階段結束時 Boss 的血量還在一半以上，會繼續顯示成前一階段；舊記錄只記了 Boss 的名字，這三個階段無法恢復。絕龍詩在 P4 之後如果營救失敗、回到 P2 重新打，會顯示成 P5。
- 沒有專屬階段表的副本裡，下一階段的 Boss 如果和上一階段的敵人同場超過 10 秒，不再單獨算一個階段。
- 仿生石 v0.1.0.0 的適配和新的隨包郵差只做了離線檢查，沒有在遊戲裡驗證過；仿生石可以重新匯入 v0.0.4.2。
- 掉幀與同步資料的最佳化是用壓力測試和測量驗證的，沒有在遊戲裡實測。

## 使用說明

透過台服獨立訂閱更新至 1.0.0.11，完成後請完整重啟遊戲。這次不需要重新登入，設定、好友和雲端備份都不受影響。

## 驗證範圍

台服 Release 構建通過；Scanner、Package、Host、Legacy Resource 冒煙測試由台服 CI（.NET 9）執行。隨原專案帶入的檢查：七個絕本逐步核對階段推進與舊記錄更正；人多戰鬥的壓力測試；同步資料裡未變化的增益減益由 Host 沿用；解析範圍預設值與舊設定遷移；職能分欄榜單的捲軸；回饋視窗與描述框換行；橫版榜單收窄；仿生石 v0.0.4.2 和 v0.1.0.0 改寫後的逐項檢查（不載入、不執行 v0.1.0.0）；隨包郵差的檔案摘要；缺少 WebView2 Runtime 的提示；診斷日誌保留出錯記錄的完整內容。說明截圖以台服構建重新產生。
