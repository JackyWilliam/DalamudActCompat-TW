# v0.4.4.3

## 外觀更新

- 新增彩蛋皮膚「澄光流璃」與「無相玄墨」，發現後可在外觀與皮膚中預覽、應用，並隨配置雲同步儲存。
- 澄光流璃採用偏白的半透明玻璃和墨色文字，實時模糊遊戲背景，圓角邊緣呈現折射、色散與懸停高光。
- 無相玄墨採用純黑底色與灰白控制元件、文字，保留清晰的內容層次。
- 修復玻璃背景細紋理的顆粒感，增強邊緣折射，並調整右上角關閉按鈕的內邊距。
- 修復雲同步狀態彈窗在部分字型縮放下始終顯示多餘捲軸的問題；內容超出視窗時仍可正常滾動。

## 更新說明

使用原衛月訂閱正常更新，更新後請完整重啟遊戲。現有配置、已發現皮膚和統計背景設定均保留。

仍安裝錯誤編號 `4.4.0.0` 的使用者，請先用同一倉庫中的 **DACT 修復工具** 修復到 `0.4.4.0`，完整重啟後再更新到 `0.4.4.3`；無需重置配置。
