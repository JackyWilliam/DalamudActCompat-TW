# v0.4.4.0

## 本次更新

- 更正此前錯誤的 `4.4.0.0` 釋出編號，正式版本統一為 `0.4.4.0`，保留全部已完成功能。
- 適配 7.56 熱修客戶端 `2026.09.15`：更新 ACT 解析器、解混淆依賴與網路事件表，並同步抹茶、銀山雀兒使用的事件對映。修正舊事件編號無法匹配新客戶端技能包的相容問題。
- 新增皮膚系統：一級及以上贊助帳號可永久解鎖「艾歐澤亞」淺色皮膚，資格由後臺人工設定；另有可透過探索客戶端發現的彩蛋配色。
- 淺色皮膚複用本機遊戲的視窗、按鈕、標籤和圖示素材；最佳化文字居中與 Logo 圓角，補齊雲同步、好友狀態和下拉選單的金屬邊框，修正主窗／好友欄底邊及佈局編輯器儲存、取消按鈕位置。
- 戰鬥統計可分別設定背景顏色與不透明度，支援恢復預設和完全透明，改善文字可讀性。
- 修復更換主介面皮膚後戰鬥統計出現米色底板的問題：經典榜、橫版及職能分欄的顏色和透明度獨立於皮膚，編輯預覽不再疊加子視窗背景。
- 新增「團隊秒傷」槽位內容：在佈局編輯器新增或選擇槽位後啟用。按全隊總傷害除以有效戰鬥時長計算，包含已歸屬的極限技，不受「只顯示自己」及職能篩選影響。升級不會改變現有槽位佈局。
- 皮膚頁支援預覽、應用與明確的退出操作；啟用遊戲內愛發電入口。

## 更新說明

更新後請完整重啟遊戲，使解析器和獨立 Host 一起更新。贊助權益需要登入對應雲帳號，可在帳號頁重新整理權益。

### 已安裝錯誤編號 4.4.0.0 的使用者

更簡單的方法：在同一個衛月倉庫搜尋安裝獨立外掛 **DACT 修復工具** → 停用 DACT 主外掛（不要解除安裝）→ 工具裡點選修復 → 完整重啟一次遊戲並重新啟用 DACT。[操作說明](https://github.com/JackyWilliam/DalamudActCompat/tree/main/tools/DACT.Repair)。工具自動備份舊安裝並保留配置，不是需要另外執行的 Windows 軟體。也可按下面步驟手動處理。

衛月只把數值更高的版本視為更新，因此不會自動從 `4.4.0.0` 降到 `0.4.4.0`。請先保留配置備份，再按順序操作：

1. 在 `/xlplugins` 的已安裝列表中禁用 DACT，點選垃圾桶解除安裝；不要選擇「重置外掛資料」或刪除 `pluginConfigs`。
2. 完整退出並重新啟動遊戲，讓衛月完成舊版本清理。
3. 在外掛列表確認顯示 `0.4.4.0` 後重新安裝，再完整重啟遊戲。

普通解除安裝與配置重置是不同操作；本次更正釋出編號並修復皮膚影響統計背景的問題，配置格式保持相容。仍在 `0.4.3.1` 的使用者正常更新即可，無需重灌。依據：[衛月版本比較與解除安裝清理實現](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Plugin/Internal/PluginManager.cs)、[外掛解除安裝與重置入口](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Interface/Internal/Windows/PluginInstaller/PluginInstallerWindow.cs)。

解析鏈版本：FFXIV ACT Plugin 3.0.3.1、IINACT 2.10.3.8、OverlayPlugin Core 0.19.108、Unscrambler.XIV 7.56.1；Machina 使用保留 DACT 相容修改的原始碼分支並同步 7.56h 事件表。

已驗證國服／國際服四種坦克無敵技能的合成事件解混淆、配置儲存和原生介面互動。實際語音、字幕及副本繪圖仍需遊戲內驗收；本次不宣稱之前報告的絕伊甸／絕妖星全部缺圈問題已修復。若仍無提示，請保留髮生時間、技能名及該次 `dalamud.log`。
