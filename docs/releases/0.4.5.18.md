# v0.4.5.18 台服測試候選版

台服以自身 API 13 / .NET 9 依賴重新移植、構建與驗證。維持台服倉庫、繁體中文預設與既有解析適配，不包含 Matcha。此前 .17 發布暫停，本次由 .16 直接更新至 .18。

## 本次更新

- 修復 PostNamazu `command` 靜默派發語義，保留 `normalcommand` 與合法遊戲、外掛指令。
- 增強 `Redraw` / `108` 技能、目標 Address 與重繪回呼診斷。
- 整合尚未發布的 .17 修復：野外木人 DPS/rDPS、近期戰鬥頁的大字號和窄視窗布局、擴充套件無主人 ID 相容性、未知雲端皮膚選擇保留；延續既有時鐘偏移與 `/actcompat` 提示修復。
- 重新收集台服 Host、Cactbot 與擴充套件資源，提供整包 SHA-256、依賴鎖檔及逐檔資源內容雜湊。

## 驗證邊界

台服獨立命令入口、真實隨包 Triggernometry 診斷及 11 個原清特效節點的隔離回放通過。回放採用合成 NPC Address，原生回呼由記錄器替代，不能視為遊戲內視覺驗收。

**妖星指定 NPC 的實戰清特效尚未確認，台服原生重繪、封包 hook、VFX 等遊戲內行為仍待驗收。** 本版維持測試候選版，不宣稱已徹底修復。阿洛 CDN 間歇 DNS 更新問題未包含在本版修復內。

透過台服獨立訂閱更新，完成後請完整重啟遊戲。
