# v1.0.0.0 台服測試候選版

移植原專案 DACT 1.0.0.0 的全部介面與功能，台服以自身 API 13 / .NET 9 依賴重新構建與驗證。維持台服倉庫、繁體中文預設與既有台服解析、FFLogs TW 查詢及 SilverDasher 台服資料表。

## 本次更新

- **全新控制中心**：頂欄放全域搜尋、雲端同步狀態、回饋與說明；左側導覽放首頁、戰鬥統計、戰鬥記錄、懸浮窗、擴充功能、好友、AI 助手，分隔線下是帳號與雲端同步和設定。首次開啟會有一段 1.0 新版導覽，可隨時略過。
- **全域搜尋**：按 Ctrl+Shift+K（可在設定裡改鍵或關閉）或點頂欄搜尋框，設定項、頁面與使用說明一起搜，按 Enter 直接跳轉，開關類設定可以在結果裡直接切換。
- **皮膚**：每款皮膚都有自己的控制項、下拉選單、浮層與對話框樣式；在「設定 → 外觀與皮膚」可以先預覽再套用。艾歐澤亞改用遊戲視窗的金屬邊框，懸停說明也套用同款外框。
- **好友**：好友從頂欄移到左側導覽，有獨立的好友頁與可單獨開啟的聊天視窗；收發訊息有動態效果，來信氣泡裡可以直接「全部展開」開啟聊天。
- **戰鬥記錄**：原獨立視窗併入控制中心，新增「開荒進度」，記錄每次打到哪裡與最常見的團滅點。
- **戰鬥統計樣式編輯器重做**：在頁面預覽裡點選欄位，右側屬性自動切換到所選欄位。
- **AI 助手**：診斷問題、戰鬥複盤、使用問答。預設關閉，需要你自己的 API Key，Key 只保存在本機。
- **回饋**：頂欄回饋按鈕可提交問題、建議或其他，附上截圖、診斷日誌與 AI 對話；回覆會出現在好友 ·「官方通知」。
- **帳號**：每個帳號最多同時登入 5 台電腦，第 6 台登入時可以選擇登出其中一台或全部登出；裝置以 Windows 電腦名稱顯示。
- **其他**：場景方案；DACT 樣式的選擇檔案／資料夾視窗；登入與註冊頁右上角加入說明；Triggernometry 與擴充功能更新檢查在系統 DNS 解析失敗時改用 Cloudflare／Google 的 DNS-over-HTTPS，更新來源失敗時顯示具體原因並自動重試一次。
- **名稱**：遊戲內視窗、說明頁版權與診斷報告改用 DACT 名稱；診斷報告標題標示「DACT (TW)」，方便區分台服回報。

## 台服移植說明

- 「開荒進度」的團滅／通關判定與首領辨識改用 API 13 的對應介面。
- AI 助手所需的 System.Text.Json 10 在 .NET 9 上隨套件提供。雲端帳號請求改用外掛自身的 JSON 序列化，避免與框架內建版本衝突導致無法登入；新增模擬 Dalamud 外掛載入環境的回歸測試。
- 首頁的「遊戲區域」維持固定為台服；FFLogs 估算說明改為 TW 區域榜單。

## 使用說明

透過台服獨立訂閱更新至 1.0.0.0，完成後請完整重啟遊戲。

**更新後需要重新登入一次**：為了讓「最多 5 台裝置」按電腦名稱記錄裝置，所有帳號已統一登出一次；重新輸入帳號密碼登入即可，設定、好友與雲端備份都不受影響。仍使用舊版時也可以重新登入，但同一帳號在第 6 台裝置登入時，舊版只會提示先更新。

AI 助手預設關閉，不開啟就不會產生任何網路請求；開啟後請求直接從你的電腦送到你填寫的服務商，不經過 DACT 伺服器。

## 驗證範圍

台服 Release 構建，以及 Scanner、Package、Host（含隨包 Triggernometry 2.4.3.0 的改寫與執行，3 處下載用戶端改走 DNS 備援）、Legacy Resource 冒煙測試通過；新增的 Dalamud 外掛載入環境測試確認雲端登入 JSON 與 AI 用戶端可在隔離載入下運作。帳號、封禁恢復、選擇檔案視窗、好友與來信氣泡、說明頁等原生介面測試，以及戰鬥記錄 1620 組皮膚／語言／版面組合驗收通過；說明截圖以台服構建重新產生，介面在繁體中文、簡體中文、日語、德語、法語下核對文案完整。

**本版尚未在台服遊戲內實機驗證**，台服原生重繪、封包 hook、VFX、開荒進度判定與 1.0 新介面的實際表現仍待驗收，維持測試候選版。DNS 備援只解決解析失敗；更新來源節點本身無法連線時仍可能逾時，此時會提示原因並在下次檢查時重試。
