# v0.4.4.1

## 戰鬥統計

- 修復已切換到“24 人本”仍只顯示本隊 8 人的問題，補齊聯盟另外兩隊的成員讀取。
- 修復沒有戰鬥記錄時，自定義編輯器“頁面預覽”底部的全隊屬性欄不可見的問題。

## 皮膚與雲同步

- 彩蛋解鎖記錄和已選皮膚隨加密雲備份恢復，修復恢復後再次儲存或重啟丟失解鎖的問題。
- 檢測到預設配置時，自動和手動雲同步都會跳過上傳，保留已有云端備份；無法確認是預設內容的第三方配置仍保留同步。
- 新增可探索的「緋夢霓光」配色，精簡皮膚預覽頁多餘的關閉按鈕。

## 帳號與聊天

- 贊助者名字顯示為紅色，後方新增皇冠與等級方框；管理員等其他標識排在其後。贊助資格永久有效，等級由後臺設定。
- 首次獲得贊助身份時顯示慶祝視窗；確認後再次登入或升級等級不重複彈出，已有贊助者也會獲得一次提示。
- 聊天已讀位置隨帳號儲存，成功同步後重新安裝也能恢復；新來信仍正常顯示未讀。
- 修復從來信氣泡點選“全部展開”沒有清除未讀的問題；現在會開啟對應聊天並回到最新訊息，也修復氣泡蓋住聊天時按鈕點選失效的問題。
- 聊天視窗採用 DACT 自定義標題欄，保留拖動、關閉、縮放及身份標識。
- 管理後臺可檢視帳號最近上報的 DACT 版本，方便定位版本相關問題。

## 更新說明

更新後請完整重啟遊戲。舊版本重灌已經丟失的本機已讀記錄無法追溯恢復；更新後重新開啟對應聊天，新已讀位置會儲存到帳號。
