# RPets 共用登入（本地試用配套）

DACT 0.4.1.0 在完整好友功能基礎上加入 RPets 共用登入，伺服器介面不變。RPets 作為獨立外掛安裝。

同一衛月配置目錄的 `pluginConfigs/Raynording.Account/session.dat` 儲存 DPAPI 加密會話、持久登入偏好及遞增修訂號。任一外掛登入、切號或退出後，另一個外掛約一秒內發現變更，並在伺服器驗證令牌及帳號名稱後啟用。過期、撤銷、封禁仍由現有伺服器判斷；不共享明文密碼。

`SharedAccountStore.cs` 與 RPets 內的副本保持位元組一致。命名互斥鎖和原子檔案替換保證兩外掛不會同時覆蓋，釋出須匹配請求開始時的修訂號，舊登入結果無法覆蓋較新的退出/切號。退出使用明確空會話標記，不能把刪除檔案當作重新匯入舊憑據的許可。未記住登入時，只有同一遊戲 PID 和啟動時間可恢復共享會話。

舊 DACT 自動登入會在服務端驗證後遷移；舊憑據格式繼續相容恢復金鑰/備份。共享匯入仍呼叫原備份與邀請介面；不會改變原好友聊天、20/3 保留、通知、狀態或其他解析功能。

驗證：完整 Package/FFXIV_ACT_Plugin 迴歸；RPets 測試工程透過外部專案別名引用實際 DACT 客戶端，兩邊使用隔離配置和模擬服務驗證 RPets 先啟動舊憑據遷移、雙向登入/退出、不記住登入、遲到登入和伺服器拒絕令牌。實際遊戲雙外掛載入仍須使用者驗收。
