# 皮膚與統計背景

設定與帳號頁頂部的「外觀與皮膚 → 管理皮膚」提供預設外觀、帳號贊助皮膚和探索配色。

## 預覽與退出

- 卡片使用標題欄、標籤、按鈕組成的外觀縮圖，右側展示選中皮膚的大預覽。窄視窗或大字型時改為下拉選擇器，避免必須先滾過大圖才能切換。
- 點選卡片只改變臨時預覽；「應用皮膚」才修改偏好並由主頁面儲存。仍可預覽未獲授權的贊助皮膚，但不能應用。未發現彩蛋只顯示神秘插圖，不洩露配色或名稱。
- 底部固定「返回設定」「應用皮膚」。返回或 Esc 回到設定；標題欄關閉按鈕隱藏主視窗；未應用的預覽不會儲存。已有彈窗或文字輸入獲得焦點時，皮膚頁不搶佔 Esc。
- 切換主標籤、退出帳號或關閉主視窗會離開皮膚頁；下次開啟從當前生效外觀開始。

## 帳號權益

- 三級及以上贊助解鎖「艾歐澤亞」淺色皮膚。等級由獨立管理後臺手動設定，沒有有效期。一級、二級仍保留贊助身份標識與紅色名字。
- 當前已登入帳號的 `auth/me` 或邀請摘要返回 `sponsor: { tier: 1 }`。舊服務端不返回該欄位時按 0 級處理；管理員身份不會自動授予皮膚。
- 權益不存入本地配置或加密備份。切換帳號、登出或封禁後回到預設外觀，但保留偏好的皮膚 ID，以便重新登入獲授權後恢復。
- 既有帳號心跳同步等級，也可點選「重新整理權益」。客戶端皮膚屬於本地顯示偏好，不能將開源客戶端顯示門禁視為防篡改 DRM。
- 雲帳號頁「支援 DACT」中的「愛發電支援」使用預設瀏覽器開啟 `https://ifdian.net/a/raynor`。贊助後由管理員核對帳號並設定等級；按鈕本身不自動授予權益。

## 原版淺色素材

`GameSkinAssets` 透過 Dalamud `ITextureProvider.GetFromGame` 讀取玩家本機 SqPack 的 `ui/uld/img01/`，優先 `_hr1.tex`，缺失時使用普通解析度。外掛包不包含匯出的遊戲素材。

- Character/Social 的 `TabButtonA`：88×26 切片，16 畫素左右固定端帽，第二行含原版金色選中標記。
- `ButtonA`：100×28 原版按鈕，保留左右端部；文字按實際字形邊界在可見按鈕面內居中，排除下方透明陰影。
- `WindowA_BgSelected_*`：九塊視窗背景，中心與邊緣按原尺寸平鋪，避免放大紙張紋理。
- `WindowA_Button`、`CircleButtons`、`CheckBoxA`：關閉、幫助、設定圖示和選擇框；好友入口使用原版主選單社交圖示。
- 主標題欄 Logo 直接裁切為圓角，保留十次點選的探索命中區域。

文字仍由 Dalamud 當前字型渲染，DACT 頁面內容及排列沿用自身功能佈局。以上為原素材複用，不應表述為整個頁面已經完成與遊戲逐畫素一致的驗收；執行中游戲字型、縮放、懸停和焦點效果需要遊戲可正常載入外掛後對照。

## 探索配色（維護說明）

發現後顯示皮膚名稱並儲存到常規配置；未發現時不在客戶端透露具體步驟。

- 森之青玉：主介面左上角 Logo 連續點選 10 次。
- 月下紫晶：標題版本號連續點選 7 次。
- 暮光琥珀：同一次外掛執行中訪問全部六個主頁面。
- 緋夢霓光：皮膚頁「選擇喜歡的外觀」連續點選 5 次，儲存 ID 仍為 `neon-pink`。
- 澄光流璃 / Lucent Glass：皮膚頁頂部「設定與帳號 / 外觀與皮膚」連續點選 6 次，ID 為 `liquid-glass`。
- 無相玄墨 / Obsidian Void：皮膚頁「點選卡片檢視預覽，應用後自動儲存。」連續點選 7 次，ID 為 `obsidian`。
- 點選序列相鄰間隔不超過三秒；同一皮膚只提示一次。恢復出廠設定會清除這些本地發現。
- 解鎖不會自動應用，無贊助門檻。發現和所選皮膚隨現有加密雲備份儲存、恢復；服務端不需要新增欄位。

## 液態玻璃與純黑材質

澄光流璃使用獨立的 Direct3D 11 著色器。透過公開 `IUiBuilder.DeviceHandle` 獲取裝置，在 ImGui 繪製回撥中複製當前面板背後的已繪製區域，再進行橫縱兩遍連續高斯模糊、圓角 SDF 遮罩、24px 邊緣折射、2px 色散和指標高光。預設主窗疊加 56% 偏白底色，使用墨色文字，圓角為 14px；畫素引數隨字型縮放。主窗、標題、導航、按鈕和皮膚預覽共用該材質。標題操作組整體向內縮排 10px（隨字型縮放），讓關閉按鈕的繪製和點選區域都避開玻璃邊緣。

舊版間隔 3px 的 5×5 取樣會遺漏細紋理，產生顆粒和條紋。現在按物理畫素構建連續高斯核（預設 sigma=3，最高8），合併相鄰畫素的雙線性取樣，先完成模糊再折射，縮放時也不拉大采樣間隙。臨時紋理與取樣紋理一起復用、釋放；合成前恢復原輸出目標和視口。

取樣發生在正確的視窗層次，不使用舊幀截圖；生產實現沒有 CPU 畫素回讀、Present 鉤子或遊戲記憶體偏移。取樣紋理按需增長並複用，切換離開皮膚/預覽與解除安裝時釋放；異常會記錄一次並退回可讀的普通材質。繪製結束恢復所有本次修改的 D3D11 狀態，統計視窗仍在皮膚作用域之外。

無相玄墨的主畫布為不透明 `#000000`，普通控制元件為近黑色，懸停、文字和強調色使用灰白層次。職業、狀態和身份的語義配色維持原行為。

視覺參考為使用者提供的 AutoTriadC 截圖及 [Apple Liquid Glass 說明](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)。[使用者提供的訂閱](https://raw.githubusercontent.com/extrant/DalamudPlugins/main/pluginmaster.json) 指向外掛二進位制分發；本實現沒有複製該外掛或 Apple 的程式碼。已驗證真實 D3D11 材質行為，但尚未完成遊戲實機與參考畫面的逐畫素一致驗收。

## 統計背景

佈局編輯器中每種模板獨立設定 RGB 背景色和背景不透明度，職能分欄的兩欄分別儲存。提供恢復預設和完全透明按鈕；選擇顏色時，若原先完全透明，自動提高到 85% 以顯示顏色。儲存與取消沿用編輯器事務。

淺色且不透明度至少 65% 的背景使用深色文字。背景與客戶端皮膚獨立，職業配色不被替換。配置版本 16→17 時，將舊橫版已被忽略的不透明度轉為 0，保持使用者升級前的透明外觀；其他模板保留原值。

## 彈窗、底邊與統計槽位

- 淺色皮膚的下拉選單、雲同步狀態和好友狀態彈窗複用遊戲視窗的金屬邊框；彈窗按實際內容自動調整高度，溢位時保留滾動。雲同步狀態增加關閉按鈕，支援 Esc。
- 雲同步狀態彈窗的縮放內邊距對齊整數畫素，消除 16px 字型下約 0.12px 的虛假溢位和常駐捲軸；八款皮膚及四檔字型迴歸覆蓋此場景，長狀態/小視口仍可滾動。
- 主頁面與好友抽屜避開遊戲素材底部的透明尾部，內容不再蓋住下邊框。佈局編輯器按實際皮膚按鈕高度預留底部操作區；儲存、取消在字型縮放後仍保持可達，未儲存退出確認沿用原有行為。
- 在佈局編輯器新增槽位或更改「槽位內容」可選擇「團隊秒傷」。它與全隊總傷害、總治療一樣顯示在團隊彙總區，不重複放在每名玩家行中，也不作為個人排序依據。
- 團隊秒傷 = 當前戰鬥全隊總傷害（含已歸屬的極限技）÷ 有效戰鬥秒數，顯示整數；有效時長優先使用解析器的 CombatDuration，否則使用戰鬥起止時間，分母最少一秒。只顯示自己、職能篩選不改變全隊口徑。
- 三種模板均可配置；職能分欄兩欄獨立儲存。經典榜的固定 24 人緊湊佈局及關閉彙總區的模式維持原規則。升級不自動插入可見槽位，不改變既有使用者佈局；新列舉值追加，相容舊配置編號。

## 驗證記錄補充

- 彈窗原生驗證覆蓋 100%、140% 的邊框、關閉、Esc、下拉選擇和樣式棧平衡；好友驗證覆蓋螢幕邊緣、75%～200% 字型及長狀態真實溢位。
- 三種編輯器模板在 880×590、85%／100%／140%／200% 字型下驗證儲存取消完整可見、儲存一次及乾淨取消關閉。
- 團隊秒傷驗證全隊共享時長、極限技、進行中戰鬥、清空及零時長，四份模板配置的克隆和序列化，以及舊列舉編號相容。

- PackageSmoke 預設執行許可權、配置遷移、序列化、發現和背景隔離驗證。
- `--skins-only`：設定 `DACT_TEST_CIMGUI` 後執行真實 cimgui 離屏繪製、十次 Logo 點選、皮膚預覽/應用/返回/Esc/關閉與未授權點選、編輯器儲存/取消；可設 `DACT_TEST_GAME_SQPACK` 使用本機原版素材，`DACT_NATIVE_UI_OUTPUT` 輸出預覽。中英文及 760×520、140% 字型檢查底部退出可達。
- `--liquid-glass-only`：使用本機 D3D11 硬體裝置執行著色器編譯、真實背景模糊、30組細條紋週期/方向/縮放去顆粒、白色半透底、增強折射/色散、中心保護、圓角/父級裁剪、懸停、淡出、視口偏移、輸出目標及視口恢復、紋理複用及 GPU 時間測量，不載入真實遊戲外掛。
- 為 `--skins-only` 增加 `DACT_TEST_GPU_GLASS=1`，會將實際 cimgui 回撥與真實 GPU 材質合成到測試背景上，輸出兩款皮膚的 PNG；棋盤是取樣驗證背景，不是皮膚紋理。
- `--friends-native-only` 同樣設定 SqPack 和輸出目錄可額外輸出淺色皮膚的真實好友抽屜截圖；帳號與訊息來自隔離夾具，不連線實際好友服務。
- 額外繪製 85%、100%、140% 下的中文、英文及混合文字按鈕；已有好友原生測試覆蓋縮放、點選與焦點。
- `--skins-api-only` 由私有服務端合成測試夾具呼叫，驗證真實 C# HTTP 帳號切換、舊服務端和過期響應隔離。

釋出需先部署服務端權益欄位和管理入口，再發布客戶端。皮膚邏輯不修改遊戲熱修相容門禁；0.4.4.0 同時包含的解析更新詳見 [7.56 熱修依賴審計](bundled-plugin-audit-2026-09-17.md)。
