# 最高傷害數字格式與 HTML 脫戰隱藏

## 最高傷害

在“自定義”中選中對應視窗的“最高傷害”欄目，“傷害數字格式”可選擇：

- 縮寫（K / M）：沿用原有縮寫，例如 `128.5k`。
- 完整數字：例如 `128456`，不省略位數、不加千位分隔符。

經典榜、橫版與 D/T/H 職能分欄分別儲存；複製槽位和儲存、取消編輯沿用現有配置流程。舊配置預設繼續使用縮寫。

橫版只有一個最高傷害欄目時顯示技能和數值；舊自定義佈局如果將技能與數值分成兩個槽位，則在數值槽位調整格式，保留分列布局。

## HTML 懸浮窗

在懸浮窗頁面選中一個 HTML 視窗，在該視窗的設定中勾選“脫戰隱藏”。這是每個例項自己的設定，預設關閉，沒有新增全域性開關。

- 已開啟的視窗脫戰時隱藏，進戰時恢復。
- 臨時隱藏保留瀏覽器例項和啟動顯示偏好。
- 編輯視窗位置時暫時顯示，完成編輯後恢復脫戰隱藏。
- 手動關閉的視窗不會因進戰重新開啟。
- 原有遊戲失焦隱藏規則繼續生效。

## 驗證

PackageSmokeTests 的 `--display-options-only` 覆蓋數字格式、舊配置預設值、儲存/複製、視窗間隔離，以及真實 WinForms 視窗的進戰/脫戰/編輯/失焦/手動關閉行為。測試視窗位於螢幕外且不啟用，不啟動遊戲或 WebView、不操作滑鼠。
